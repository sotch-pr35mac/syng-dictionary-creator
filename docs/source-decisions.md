# Multi-source production decisions

Schema 4 uses source-specific admission and enrichment rules. These decisions are part of the generator contract.

- Lexical equality is the exact normalized `(simplified, traditional, numbered Mandarin Pinyin)` tuple. Written-family membership, source grouping IDs, English text, and source priority never establish identity.
- CC-CEDICT establishes the initial identity set. Wiktionary may establish a new entity only from one complete, unambiguous tuple. Chinese Notes never establishes an entity.
- `復明` is the capitalization/scope regression case: a Wiktionary record spanning `fu4 Ming2` and `fu4 ming2` is rejected rather than enriching either. `煙火` fixes the distinct `yan1huo3` and `yan1huo5` boundary.
- Definition sharing uses the exact gloss and ordered context chain after source-specific structural parsing. It does not use case folding, punctuation rewriting, stemming, or semantic similarity.
- Source attribution belongs to each assertion. Exact text can collect multiple sources, but POS, qualifiers, context, examples, notes, classifiers, and pronunciations retain independent attribution and scope.
- CC-CEDICT slash and semicolon separators produce ordered definition entries. `CL:` and `Taiwan pr.`/`also pr.` are extracted only through reviewed grammars. Complete parenthetical spans are structured only when they match the closed CC-CEDICT label enum; other parentheticals remain literal text.
- Chinese Notes uses exactly 16 TSV fields. It is enrichment-only: no identity or gloss is published from it. A row must exactly match an existing complete tuple, and definition-scoped metadata must route through one exact existing gloss. Initially only closed grammar/lexical-kind values and domain qualifiers are whitelisted. A `\N` traditional value is incomplete and is not inferred; suppressed records are counted by reason.
- Wiktionary retains every distinct explicit Mandarin Pinyin reading. A multi-reading record can enrich one CC-CEDICT owner when matching written forms and primary/alternative readings identify it uniquely; a single-reading record remains its own exact identity. Cumulative gloss ancestors remain ordered context. Explicit non-Mandarin senses are excluded.
- Wiktionary examples are paired only within one sense. Exact normalized English text (including both sides having no English) plus equal simplified and traditional conversion keys define a candidate pair. Existing script tags take precedence; otherwise script is inferred with the pinned `character_converter`. Ambiguous conversion classes are not merged. Every accepted example publishes both script forms: source-attested text is never replaced, while a missing counterpart is generated as a canonical display fallback.
- Every lexical unit carries one finite, nonnegative document-normalized commonness score from the locally generated `syng-word-frequency` database. An identity absent from that database receives `0.0`. Commonness is ranking evidence only and never admits, rejects, merges, or filters vocabulary.
- Closed enums are deliberately conservative. A new source POS or Chinese Notes grammar value blocks publication until the parser and schema mapping are reviewed. Unclassified prose is never guessed into a typed enum.
- Generated runtime keys are ephemeral and sorted by `LexicalId`; only `LexicalId` is persistent. Schema 4 remains unreleased, so the refined example representation is incorporated into that contract while identity version 1 remains unchanged.

The source revisions, checksums, license evidence, parser versions, copyright and modification notices, and attribution strings are maintained in `sources.lock.json`. The combined bundle uses CC-BY-SA-4.0 as its adapter's license for compatible adapted material; WordNet-derived morphology remains under the separate WordNet License and is accompanied by `LICENSE-WORDNET.txt`. Every build emits human-readable notices plus per-identity Wiktionary entry links. The source loader rejects unreviewed license identifiers, while `deny.toml` guards the creator's GPL-compatible dependency-license allowlist. Representative regression cases live beside the Rust adapters and identity implementation as unit tests, so they cannot drift away from executable behavior.
